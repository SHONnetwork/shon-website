SHONnetwork Phase 7: Living Arrangements

Upload listings.html and discover.html to the repository root on GitHub. No SQL changes are required if Phase 4 was already installed successfully.

Living arrangements are stored using the existing discovery_tags array, so they can be selected alongside the existing six visual categories. Other / specify adds a custom Living: tag. Existing listing tags remain intact. Public Discover includes a separate living-arrangement filter.

Important: These files are prepared against the Phase 5 listings page and Phase 6 Discover page. Back up your current files before replacing them, and test saving, editing, public visibility, and filtering on the live website. The code has not been verified against your live Supabase data.
